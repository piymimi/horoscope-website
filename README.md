# Daily Horoscope Website

A beautiful, interactive daily horoscope website featuring all 12 zodiac signs with detailed readings, planetary positions, and lucky numbers.

## Features

- **All 12 Zodiac Signs**: Complete information for Aries, Taurus, Gemini, Cancer, Leo, Virgo, Libra, Scorpio, Sagittarius, Capricorn, Aquarius, and Pisces
- **Daily Horoscopes**: Unique horoscope readings for each day covering:
  - Daily Overview
  - Love & Relationships
  - Career & Finances
  - Health & Wellness
- **Planetary Positions**: Detailed planetary information including:
  - Sun, Moon, Mercury, Venus, Mars, Jupiter, Saturn, Uranus, Neptune, and Pluto positions
  - House placements
  - Key aspects between planets
- **Lucky Numbers**: Daily generated lucky numbers for each zodiac sign
- **Interactive Interface**: 
  - Beautiful gradient backgrounds
  - Clickable zodiac cards
  - Detailed view with planetary information
  - Smooth animations and transitions
  - Responsive design for mobile and desktop

## How to Use

1. **Open the Website**:
   - Simply open `index.html` in a web browser
   - Or use a local server: `python3 -m http.server 8000`

2. **View Horoscopes**:
   - Browse all 12 zodiac signs in the main grid
   - Click on any zodiac card to see detailed horoscope
   - Use the sign selector at the top for quick access

3. **Read Your Horoscope**:
   - Each sign shows a preview in the main view
   - Click to see the complete daily reading
   - View planetary positions and aspects
   - Check your lucky numbers for the day

## Files

- `index.html` - Main HTML structure
- `styles.css` - Beautiful CSS styling with gradients and responsive design
- `script.js` - JavaScript functionality with zodiac data, horoscopes, and interactive features

## Technical Details

- **Pure HTML/CSS/JavaScript**: No external dependencies required
- **Font Awesome**: Icons loaded via CDN for visual appeal
- **Responsive Design**: Works on mobile, tablet, and desktop
- **Daily Rotation**: Horoscopes rotate between multiple variations based on the day of the month
- **Random Lucky Numbers**: Generated dynamically for each viewing
